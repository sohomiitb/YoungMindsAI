# My Simple App

This is a basic HTML, CSS, and JavaScript app. It displays a greeting and a button. When you click the button, an alert appears.

## Folder Structure

```
my-simple-app/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Open `index.html` in your browser.
2. Click the button to see the alert.

## Deploy to Netlify

1. Zip this folder.
2. Go to [Netlify](https://www.netlify.com/).
3. Drag and drop your zipped folder to deploy.

Enjoy!
