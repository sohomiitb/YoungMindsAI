# YoungMindsAI Website

This is the official website for **Dr. Sohom Mandal (PhD, PEng, MBA Candidate)**, an AI and Data Science Educator, and the YoungMindsAI platform. The site showcases services, learning resources, and contact information for students and collaborators.

---

## Features

- **Modern Responsive Design:** Built with HTML, CSS, and JavaScript for all devices.
- **About Section:** Introduction, credentials, and stats about Dr. Sohom Mandal.
- **Services:** Overview of AI workshops, coding classes, and project-based learning.
- **Learning Videos:** Embedded YouTube videos and project showcases.
- **Contact Section:** Email, phone, LinkedIn, and location details.
- **Social Footer:** Quick links to professional and social platforms.
- **Smooth Navigation:** Mobile-friendly navigation bar and smooth scrolling.

## How to Run Locally

1. **Clone or Download** this repository.
2. Open `index.html` in your web browser.
3. All features work offline except embedded YouTube videos and external links.

---

## Deployment

You can deploy this site easily using [Netlify](https://www.netlify.com/) or [Vercel](https://vercel.com/):

1. Zip the `website_build_app` folder.
2. Drag and drop the zipped folder onto Netlify or Vercel.
3. Follow their instructions to publish your site.

---

## Customization

- **Images:** Place your profile and badge images in the `image/` folder.
- **Videos:** Update YouTube embed links in `index.html`.
- **Contact Info:** Edit the contact section in `index.html` as needed.
- **Styles:** Modify `style.css` for custom colors, fonts, or layout.
